# VXSearch 1.0.0

- Tìm nhanh tệp theo tên, đường dẫn và phần mở rộng trong các thư mục bạn chọn.
- Hỗ trợ tìm tiếng Việt không dấu, lọc loại tệp và sắp xếp kết quả.
- Theo dõi thay đổi thư mục; giữ kết quả đã lập chỉ mục khi ổ đĩa tạm ngắt kết nối.
- Tìm nhanh từ menu bar, mở tệp và hiện vị trí trong Finder hoặc Explorer.
- Tự kiểm tra phiên bản mới khi mở ứng dụng; cập nhật tại Cài đặt → Cập nhật.
